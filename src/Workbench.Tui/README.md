# Workbench TUI prototype

This project is an unsupported Terminal.Gui prototype retained for design and
recovery reference. It is not part of `Workbench.slnx`, is not referenced by
the packaged `workbench` executable, and has no supported command entry point.

No compatibility, release, security-update, or test-coverage commitment applies
to this project. Reintroducing a terminal UI requires a new product decision,
current requirements and architecture, solution/package integration, and
automated interaction tests. The supported interactive surface is the local
browser UI exposed by `workbench web` and `workbench ui`.
